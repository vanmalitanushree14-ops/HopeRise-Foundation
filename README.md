# HopeRise Foundation

## 🌐 Live Demo

The HopeRise Foundation website is deployed and available online:

**Live Website:** https://hope-rise-foundation-m3jx.vercel.app/

The application can be accessed at any time for project evaluation and demonstration.

A React-based NGO Content Management System website developed for the HopeRise Foundation as part of an internship project.

## 📌 Project Overview

HopeRise Foundation is a frontend NGO website designed to present the organization's mission, programs, projects, campaigns, media, and ways for users to get involved.

The website provides a simple and user-friendly interface for visitors to explore the foundation's work, support campaigns, make demonstration donations, and contact the organization.

## ✨ Features

* 🏠 Home page with foundation introduction and impact information
* ℹ️ About Us page
* 🤝 Our Work page
* 📁 Projects page
* 📸 Media page with photos and media information
* 📝 Blog page
* 🙋 Get Involved page
* ❤️ Donation interface
* 📩 Contact Us page
* 📱 Responsive Bootstrap layout

* ✨ AOS animations
* 📊 Campaign progress section
* 📝 Contact form validation
* 💰 Interactive donation amount selection
* 🔗 Navigation between website sections

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vanmalitanushree14-ops/HopeRise-Foundation.git
```

### 2. Open the Project

```bash
cd HopeRise-Foundation
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will run locally using the Vite development server.

## 📄 Website Pages

### Home

Introduces HopeRise Foundation and highlights its mission, impact, work areas, and featured campaign.

### About

Provides information about the foundation and its purpose.

### Our Work

Displays the major areas in which the foundation works, including education, community support, and women empowerment.

### Projects

Showcases projects and initiatives carried out by the foundation.

### Media

Provides photos, videos, press releases, and electronic media links.

### Blog

Displays stories, updates, and articles related to the foundation's work.

### Get Involved

Provides different ways for visitors to participate, including volunteering, supporting campaigns, and spreading awareness.

### Donate

Provides a demonstration donation interface where users can select or enter a donation amount.

### Contact

Provides a contact form with basic validation and contact information.
