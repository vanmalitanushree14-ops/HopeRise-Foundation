# HopeRise Foundation — End-User Guide

## 1. Introduction

HopeRise Foundation is an NGO website developed to provide visitors with information about the organization's mission, programs, projects, campaigns, and community initiatives.

This guide explains how users can navigate the website and use its available features.

---

## 2. System Requirements

The website can be accessed using a modern web browser such as:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

An active internet connection is recommended when accessing the deployed website.

---

## 3. Accessing the Website

Users can access the live website through the Live Demo link provided in the project's GitHub README.

The website can also be accessed directly through its deployed Vercel URL.

---

## 4. Navigation

The main navigation bar provides access to the different sections of the website.

Available pages include:

* Home
* About
* Our Work
* Projects
* Media
* Blog
* Get Involved
* Donate
* Contact

Users can click the navigation links to move between different pages.

---

## 5. Home Page

The Home page provides an introduction to HopeRise Foundation.

Users can view:

* Foundation introduction
* Mission information
* Impact information
* Areas of work
* Featured campaign information
* Links to other important sections

---

## 6. About Page

The About page provides information about HopeRise Foundation and its purpose.

Users can learn more about:

* The foundation
* Its mission
* Its vision
* Its objectives
* Its community-focused activities

---

## 7. Our Work Page

The Our Work page presents the major areas supported by HopeRise Foundation.

Users can explore information about the foundation's programs and community initiatives.

---

## 8. Projects Page

The Projects page displays projects and initiatives associated with HopeRise Foundation.

Users can explore the available project information and understand how the foundation works toward community development.

---

## 9. Media Page

The Media page provides media-related information about the foundation.

Users can explore available photographs, videos, press information, and other media content presented on the website.

---

## 10. Blog Page

The Blog page provides stories and updates related to HopeRise Foundation.

Users can read available articles and information about the foundation's activities and initiatives.

---

## 11. Get Involved Page

The Get Involved page provides different ways for visitors to support the foundation.

Users can choose options such as:

### Volunteer

Users can click the volunteer option to express their interest in volunteering.

A confirmation message is displayed after the action.

### Support a Campaign

Users can use the campaign support option to navigate to the Donate page.

### Spread Awareness

Users can click the awareness option to receive a confirmation message about supporting the foundation's mission through awareness.

---

## 12. Donate Page

The Donate page provides a demonstration donation interface.

Users can select predefined amounts such as:

* ₹500
* ₹1,000
* ₹2,500
* ₹5,000

Users can also enter a custom donation amount.

After selecting or entering an amount, the donation button displays the selected amount.

The current donation functionality is a **demonstration interface**. No real payment is processed.

---

## 13. Contact Page

The Contact page allows users to send a message to HopeRise Foundation.

Users can enter:

* Full Name
* Email Address
* Message

### Form Validation

The website checks whether the required fields have been completed.

If required information is missing, an error message is displayed.

The email address is also checked for basic validity.

After successful submission, a confirmation message is displayed.

---

## 14. Contact Information

The Contact page provides different ways to reach the foundation, including:

* Email
* Telephone
* Location
* Working hours

Users can use the displayed information to contact the organization.

---

## 15. Responsive Design

The website uses Bootstrap responsive layout features.

This allows the website interface to adapt to different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile devices

---

## 16. Troubleshooting

### Website does not load

Check your internet connection and refresh the page.

### A page does not open

Use the navigation bar to return to the Home page and try accessing the page again.

### Contact form does not submit

Make sure all required fields are completed and that a valid email address has been entered.

### Donation button does not work

Select a predefined amount or enter a valid positive custom amount.
